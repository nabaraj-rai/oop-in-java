Class names should Start with Uppercase and should match with the program file name.
Program is written inside the main method/Function.

----------------------------------------------------------------------------------------------------------
>> Access Modifiers:
-private - Me only
-public - Everyone
-protected - My package + my children (sub classes)
-default - My package only
----------------------------------------------------------------------------------------------------------

----------------------------------------------------------------------------------------------------------
>> Datatypes:
-Primitive -> Stores Value directly
***********************************
--int - 4 bytes                > e.g: 10, -5  [Whole numbers]
--float - 4 bytes              > e.g: 3.5f  [Decimal numbers]
--long - 8 bytes               > e.g: 100000L  [Large integers]
--double - 8 bytes             > e.g: 3.1415  [Precise decimals]
--char - 2 bytes               > e.g: 'A'  [Single character]
--byte - 1 byte                > e.g: 100 (range: (-128) - 127)  [Small integers]
--boolean - 1 bit              > e.g: true/false  [Condition]
--short - 2 bytes              > e.g: 1000  [Short Integers]

-Non Primitive: -> Stores reference (object)
********************************************
--String -> Text
--Array -> List of similar types of elements (note: int[] for 1D  &  int[][] for 2D)
--Class & Objects -> like Scanner, ArrayList
----------------------------------------------------------------------------------------------------------

----------------------------------------------------------------------------------------------------------
>> Taking User-Input:
-import java.util.Scanner  --> It is importing the utility package of Java containing Scanner Class.
--java -> main package
--util -> Utilies subpackage
--Scanner -> class you want to use

- To take input, we should create an object first with the help of Scanner Class.
--> Scanner sc = new Scanner(System.in);
--Breakdown:
            Scanner -> Class Name (blueprint)
            sc -> Object reference (variable name)
            new Scanner(System.in) -> Creates a Scanner object that reads input from the keyboard.

--Common Input Methods:
        nextInt()       -> Integer
        nextDouble()    -> Decimal Integer
        next()          -> Single Word
        nextLine()      -> Full line of Text
        nextBoolean()   -> true or false

--Examples of taking Inputs:
        int a = sc.nextInt();
        String name = sc.next();
----------------------------------------------------------------------------------------------------------
